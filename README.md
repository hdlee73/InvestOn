# 투자온 · InvestOn

깔끔한 한국 관심종목 + 한국·미국 포트폴리오 Android 앱. Android 8.0 이상, 인터넷 연결 필요.

## 기능

- 한국 지수·주식·ETF 관심종목 최대 10개, 현재가·전일 대비 금액과 등락률
- 최근 1년 일별 종가 선 그래프, 기간 장중 최고가·최저가 표시, 터치 시 날짜·가격
- 목표가격 이상/이하 도달 알림. 중복 없이 1회 발송, 관리 화면에서 재활성화
- 증시 관련 최신 뉴스 5개 제목 및 원문 열기
- 한국·미국 주식/ETF 검색, 한국 6자리 코드 및 미국 티커 검색
- 직접 입력한 계좌명·주식수(소수 수량 가능)·매입단가, 수정·삭제
- 종목별·계좌별 평가액, 평가손익, 가중 평가손익률
- 이익: 빨간색 + / 손실: 파란색 ▼ / 수익률 소수점 첫째 자리
- 통화별 계좌 합계, 현재 달러/원 환율을 적용한 원화 환산 합계와 자산 비중
- 기기 로컬 저장, JSON 백업/복원, 시스템 상하단과 겹치지 않는 레이아웃
- 생성한 민트/아이보리 상승 리본 아이콘과 Android adaptive icon

## 시세와 알림: 실제 동작 범위

시세와 뉴스는 **데모 데이터 없이** 인터넷에서 요청합니다. API 키 없이 사용할 수 있도록 공개 조회 피드를 연결했습니다. 공개 피드는 정식 계약형 API가 아니므로 서비스 중단·429 호출 제한·데이터 지연·응답 변경이 발생할 수 있습니다. 현재 환경에서 시세 제공처에 직접 연결한 실기기 확인은 아직 하지 못했습니다. 검색·실시간 응답은 설치 후 반드시 확인해야 합니다.

| 항목 | 제공처 | 갱신 |
| --- | --- | --- |
| 한국 주식·ETF 현재가 | NAVER 모바일 공개 조회, Yahoo 대체 | 화면 표시 중 20초 |
| 한국 지수·미국 종목·환율 | Yahoo Finance | 화면 표시 중 20초 |
| 1년 차트 | Yahoo Finance, 한국 종목 NAVER 대체 | 1시간 캐시 |
| 뉴스 5개 | Google 뉴스 RSS | 10분 |
| 기본 백그라운드 알림 | Android JobScheduler | 약 15분, 절전 시 지연 |
| 선택적 집중 알림 | dataSync foreground service | 30초, 1회 최대 5시간 |

**20초 갱신은 거래소 실시간 스트리밍을 의미하지 않습니다.** 원시 거래시각을 표시하고 5분 이상 오래된 데이터는 `지연/장마감`으로 표시합니다. 목표가격은 거래시각 30분 이내이고 최근 조회된 시세만 검사하며, 제공처 시세가 늦으면 알림도 늦습니다. 앱 강제종료/기기 전원종료/알림 권한 차단/네트워크 없음 상태에서 즉시 알림을 보장하지 않습니다. 집중 알림은 사용자 설정에서 시작하며 Android 15+의 dataSync 시간 제한에 따라 종료합니다. 재부팅 시 집중 서비스를 강제로 시작하지 않습니다.

확실한 거래소 실시간이 필요한 경우 한국투자증권 등 공식 개인 API의 사용자 발급 키와 WebSocket 연동이 추가로 필요합니다. 이 버전에 그 연동을 완료했다고 주장하지 않습니다.

## 포트폴리오 계산

- 평가액 = 수량 × 현재가
- 매입액 = 수량 × 매입단가
- 평가손익 = 평가액 − 매입액
- 수익률 = 평가손익 ÷ 매입액 × 100
- 계좌 수익률 = 계좌 손익 합계 ÷ 매입액 합계 × 100 (종목 수익률의 단순 평균 아님)
- 매입단가는 해당 종목 통화로 입력: 한국 원 / 미국 달러
- 원화 환산은 **현재 환율을 매입액과 평가액 모두에 동일 적용**. 과거 매입 환율을 받지 않으므로 환차손익은 산출하지 않음
- 수수료·세금 제외. 시세가 없는 종목을 0원으로 계산하지 않고 `일부 자산` 경고 표시
- 계좌와 보유내역은 이 기기에만 저장. Android 자동 백업은 비활성화. JSON 내보내기 파일에는 보유내역이 포함되므로 개인적으로 보관

[투자온 1.0.1 릴리즈](https://github.com/hdlee73/InvestOn/releases/tag/v1.0.1)에서 `InvestOn-1.0.1.apk`를 내려받아 설치합니다. Android 8.0 이상. 처음 실행한 뒤 알림 권한을 허용해 주세요.

## 빌드 / GitHub 게시

Java 17, Android SDK 35, Gradle wrapper 8.9, Android Gradle Plugin 8.7.3.

```bash
./gradlew assembleRelease lintRelease
node --test tests/*.test.cjs
```

새 저장소를 `hdlee73/InvestOn`으로 만들고 이 폴더 내용을 `main`에 올리면 GitHub Actions가 빌드·lint를 수행합니다. 성공 시 `InvestOn-build-kit` artifact에서 서명 전 APK를 받습니다. 설치용 서명 APK는 Releases에서 받습니다.

빌드·검증을 마친 APK에 별도로 서명한 뒤 Releases에 게시합니다. Actions 사용 한도·네트워크·저장소 정책으로 빌드가 실패할 수 있으므로 실제 성공 여부를 확인해야 합니다.

### APK 서명

CI에서는 unsigned release APK와 Google SDK의 apksigner를 `InvestOn-build-kit` artifact로 제공합니다. 서명 키를 공개 저장소나 Actions artifact에 저장하지 않습니다. 배포 담당자가 별도로 안전하게 보관한 키로 APK에 서명하고 Releases에 첨부합니다. 다음 업데이트도 같은 키를 사용해야 기존 설치 위에 업데이트할 수 있습니다.

## 검증 상태

- 손익·계좌 합계·환산·소수 수량·부호·백업 형식 자동 테스트
- JavaScript 구문 검사
- Release APK 빌드 및 Android lint: GitHub Actions 성공
- 화면 사용 흐름 테스트: 관심종목, 차트, 국내·미국 보유종목, 혼합 계좌 합계, 목표가, 백업, 폰/폴드 화면 폭 통과
- 설치용 APK v2/v3 서명 검증: 통과
- Android 15 에뮬레이터: 최초 실행·재실행·관심종목 화면·알림 작업 등록 통과, 코스피·코스닥 실제 시세 수신 확인
- 실기기 목표가격 알림 검증: 아직 미완료

`tests/ui-smoke.cjs`는 Playwright가 설치된 환경에서 실행할 수 있는 화면/사용 흐름 테스트이며, fixture 시세는 테스트 안에서만 주입합니다. 앱에는 테스트 시세가 들어가지 않습니다.
