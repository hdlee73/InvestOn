# InvestOn

깔끔한 한국 관심종목 + 한국·미국 포트폴리오 Android 앱. Android 8.0 이상, 인터넷 연결 필요.

## 기능

- 코스피·코스닥 별도 표시, 한국 주식·ETF 관심종목(개수 제한 없음, 길게 눌러 끌어 순서 변경), 현재가·전일 대비 금액과 등락률
- 최근 1년 일별 종가 선 그래프, 기간 장중 최고가·최저가 표시, 터치 시 날짜·가격
- 목표가격 이상/이하 도달 알림. 중복 없이 1회 발송, 관리 화면에서 재활성화
- 증시 관련 최신 뉴스 10개 제목 및 원문 열기
- 한국·미국 주식/ETF 검색, 한국 6자리 코드(영문자 포함) 및 미국 티커 검색
- 직접 입력한 계좌명·주식수(소수 수량 가능)·매입단가, 수정·삭제
- 종목별·계좌별 평가액, 평가손익, 가중 평가손익률, 오늘의 손익(수량 × (현재가 − 전일 종가), 오늘 매매분 미구분)
- 이익: 빨간색 + / 손실: 파란색 ▼ / 수익률 소수점 첫째 자리
- 통화별 계좌 합계, 현재 달러/원 환율을 적용한 원화 환산 합계
- 기기 로컬 자동 저장, 시스템 상하단과 겹치지 않는 레이아웃
- 검정 배경과 흰색 상승 차트 아이콘과 Android adaptive icon

## 시세와 알림: 실제 동작 범위

시세와 뉴스는 **데모 데이터 없이** 인터넷에서 요청합니다. API 키 없이 사용할 수 있도록 공개 조회 피드를 연결했습니다. 공개 피드는 정식 계약형 API가 아니므로 서비스 중단·429 호출 제한·데이터 지연·응답 변경이 발생할 수 있습니다. Android 15 에뮬레이터에서 실제 공개 시세 수신과 국내 ETF 목록의 `200`, `삼성전기`, 신규 혼합 ETF 검색·시세·차트를 확인했습니다. 제공처 지연 여부와 백그라운드 알림은 사용자 기기 환경에 영향을 받습니다.

| 항목 | 제공처 | 갱신 |
| --- | --- | --- |
| 한국 주식·ETF 현재가 | NAVER 모바일 공개 조회, Yahoo 대체 | 화면 표시 중 20초 |
| 코스피·코스닥 지수 | NAVER 지수, Yahoo 대체 | 관심종목 탭 표시 중 10초 |
| 미국 종목·환율 | Yahoo Finance | 화면 표시 중 20초 |
| 1년 차트 | Yahoo Finance, 한국 종목 NAVER 대체 | 1시간 캐시 |
| 뉴스 10개 | Google 뉴스 RSS | 화면 활성 중 5분 |
| 기본 백그라운드 알림 | Android JobScheduler | 약 15분, 절전 시 지연 |
| 선택적 집중 알림 | dataSync foreground service | 30초, 1회 최대 5시간 |

**20초 갱신은 거래소 실시간 스트리밍을 의미하지 않습니다.** 원시 거래시각을 표시하고 5분 이상 오래된 데이터는 `지연/장마감`으로 표시합니다. 목표가격은 거래시각 30분 이내이고 최근 조회된 시세만 검사하며, 제공처 시세가 늦으면 알림도 늦습니다. 앱 강제종료/기기 전원종료/알림 권한 차단/네트워크 없음 상태에서 즉시 알림을 보장하지 않습니다. 집중 알림은 사용자 설정에서 시작하며 Android 15+의 dataSync 시간 제한에 따라 종료합니다. 재부팅 시 집중 서비스를 강제로 시작하지 않습니다.

확실한 거래소 실시간이 필요한 경우 한국투자증권 등 공식 개인 API의 사용자 발급 키와 WebSocket 연동이 추가로 필요합니다. 이 버전에 그 연동을 완료했다고 주장하지 않습니다.

## 포트폴리오 계산

- 평가액 = 수량 × 현재가
- 매입액 = 수량 × 매입단가
- 평가손익 = 평가액 − 매입액
- 수익률 = 평가손익 ÷ 매입액 × 100
- 계좌 수익률 = 계좌 손익 합계 ÷ 매입액 합계 × 100 (종목 수익률의 단순 평균 아님)
- 매입단가는 해당 종목 통화로 입력: 한국 원 / 미국 달러
- 원화 환산은 **현재 환율을 매입액과 평가액 모두에 동일 적용**. 과거 매입 환율을 받지 않으므로 환차손익은 산출하지 않음
- 수수료·세금 제외. 시세가 없는 종목을 0원으로 계산하지 않고 `일부 자산` 경고 표시
- 계좌와 보유내역은 이 기기에만 저장. Android 자동 백업은 비활성화. 설정의 수동 저장·불러오기 메뉴는 제거

## 설치

[InvestOn 1.0.9 릴리즈](https://github.com/hdlee73/InvestOn/releases/tag/v1.0.9)에서 `InvestOn-1.0.9.apk`를 내려받아 설치합니다. Android 8.0 이상. 처음 실행한 뒤 알림 권한을 허용해 주세요.

## 빌드 / GitHub 게시

Java 17, Android SDK 35, Gradle wrapper 8.9, Android Gradle Plugin 8.7.3.

```bash
./gradlew assembleRelease lintRelease
node --test tests/*.test.cjs
```

새 저장소를 `hdlee73/InvestOn`으로 만들고 이 폴더 내용을 `main`에 올리면 GitHub Actions가 빌드·lint를 수행합니다. 성공 시 `InvestOn-build-kit` artifact에서 서명 전 APK를 받습니다. 설치용 서명 APK는 Releases에서 받습니다.

빌드·검증을 마친 APK에 별도로 서명한 뒤 Releases에 게시합니다. Actions 사용 한도·네트워크·저장소 정책으로 빌드가 실패할 수 있으므로 실제 성공 여부를 확인해야 합니다.

### APK 서명

CI에서는 unsigned release APK와 Google SDK의 apksigner를 `InvestOn-build-kit` artifact로 제공합니다. 서명 키를 공개 저장소나 Actions artifact에 저장하지 않습니다. 배포 담당자가 별도로 안전하게 보관한 키로 APK에 서명하고 Releases에 첨부합니다. 다음 업데이트도 같은 키를 사용해야 기존 설치 위에 업데이트할 수 있습니다.

- 미국 지수 검색 보강: nasdaq, dow, s&p, russell, vix 등 영문·한글 별칭으로 검색
- 보유종목 입력에 매입총액 추가: 매입단가 또는 매입총액 중 하나만 입력해도 저장

## 1.0.8 변경

- 포트폴리오 현재가 전일 대비 색상(상승 빨강·하락 파랑), 보유종목 자동 관심종목 등록
- 포트폴리오 길게 눌러 순서 변경, 종목별 합산 오름차순/내림차순 정렬
- 관심종목 상단에 나스닥·S&P 500·원/달러 표시, 미국 주식·ETF·지수 선택 가능
- 뉴스 한 건씩 순환 표시, 메르의 블로그 최근 글 5개 (RSS, 실패 시 모바일 목록 대체)

## 1.0.7 변경

- 코스피·코스닥을 NAVER 지수 시세로 장중 10초마다 갱신하고, 전일 종가 대비 오늘 등락·등락률로 표시 (실패 시 Yahoo Finance 대체)
- 새로고침 화살표를 버튼 중심에 맞춘 아이콘으로 교체해 회전할 때 흔들리지 않음. 계좌 접기 화살표도 같은 방식으로 수정
- 관심종목 개수 제한 해제. 상단 ‘배치’ 메뉴를 없애고, 종목을 길게 눌러 위아래로 끌어 순서 변경
- 포트폴리오에 오늘의 손익·오늘 수익률 추가 (전체·계좌별·종목별, 환산 합계 포함)
- 두 줄 종목명 아래쪽이 잘리던 문제 수정
- 보유종목 추가 시 관심종목 목록을 먼저 표시, 관심종목 선택창의 체크 표시를 새 디자인으로 변경
- 종목이 많아도 시세 요청을 6개씩 나눠 보내고 화면을 모아서 갱신

오늘의 손익은 수량 × (현재가 − 전일 종가)이며 오늘 매매한 수량은 따로 구분하지 않습니다. 관심종목을 삭제하려면 종목을 눌러 상세 화면에서 삭제합니다. 기존 앱 위에 업데이트하면 입력 내역을 유지합니다.

## 검증 상태

- 1.0.8: 단위 테스트와 Playwright 화면 흐름 테스트(포트폴리오 길게 눌러 정렬, 종목별 정렬, 뉴스 순환, 미국 종목 선택 포함) 통과. NAVER 블로그 RSS와 해외 지수 시세는 개발 환경 네트워크 제한으로 실제 응답을 확인하지 못했고 Android 빌드는 GitHub Actions에서 확인합니다.
- 1.0.7: 단위 테스트와 Playwright 화면 흐름 테스트(길게 눌러 끌기 정렬, 오늘의 손익, 관심종목 제한 해제 포함) 통과. NAVER 지수 시세는 개발 환경 네트워크 제한으로 실제 응답을 확인하지 못했으며 APK 빌드·에뮬레이터 검증은 GitHub Actions 결과를 따릅니다.

- 손익·계좌 합계·환산·소수 수량·부호·백업 형식 자동 테스트
- JavaScript 구문 검사
- Release APK 빌드 및 Android lint: GitHub Actions 성공
- 화면 사용 흐름 테스트: 관심종목, 차트, 국내·미국 보유종목, 혼합 계좌 합계, 목표가, 여러 종목 일괄 선택, 배치 변경, 계좌 접기, 종목별 가중 합산·개별 내역 수정, 수동 새로고침, 긴 종목명·수정 버튼 배치, 폰/폴드 화면 폭 통과
- 설치용 APK v2/v3 서명 검증: 통과
- Android 15 에뮬레이터: 최초 실행·재실행·관심종목 화면·알림 작업 등록 통과, 코스피·코스닥 실제 시세 수신 확인

- 실기기 목표가격 알림 검증: 아직 미완료

`tests/ui-smoke.cjs`는 Playwright가 설치된 환경에서 실행할 수 있는 화면/사용 흐름 테스트이며, fixture 시세는 테스트 안에서만 주입합니다. 앱에는 테스트 시세가 들어가지 않습니다.
